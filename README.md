# FinTrack Frontend

This frontend follows the requested 10-screen UI structure:

1. Landing Page
2. Login
3. Register
4. Dashboard Overview
5. Transactions
6. Budgets
7. Goals
8. Reports
9. Profile
10. Responsive mobile layout

## Run

```bash
cd fintrack-frontend
npm install
npm start
```

The app opens at http://localhost:3000.

## Routes

- /
- /login
- /register
- /dashboard
- /transactions
- /budgets
- /goals
- /reports
- /profile

The forms currently navigate to the dashboard so the complete UI can be tested before connecting the backend APIs.
